╚══════════════════════════════════════════════════════════════════════════════╝

    User Taps Heart
         │
         ▼
    BaseReelCard.onFavorite()
         │
         ▼
    PropertyReelCard.handleFavorite()
         │
         ├──► API: api.properties.toggleFavorite(id)
         │         │
         │         └──► Response: { is_favourite, favorites_count }
         │
         ├──► Update local state (isLiked, favoriteCount)
         │
         └──► onFavoriteMetaUpdate(id, meta)
                  │
                  ▼
         PropertyReelsView.handleFavoriteMetaUpdate()
                  │
                  ├──► Update item in properties array
                  │
                  └──► Props flow back down
                           │
                           ▼
                  BaseReelCard receives updated props
                           │
                           ▼
                  UI updates (heart fills, count changes)


╔══════════════════════════════════════════════════════════════════════════════╗
║                        SCROLL LOCK FLOW                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

    User Swipes Image Horizontally
         │
         ▼
    BaseReelCard ScrollView
         │
         ├──► onScrollBeginDrag fires
         │         │
         │         └──► onHorizontalScrollBegin()
         │                  │
         │                  ▼
         │         PropertyReelsView
         │                  │
         │                  └──► setFeedScrollEnabled(false)
         │                           │
         │                           ▼
         │                  FlatList.scrollEnabled = false
         │                           │
         │                           └──► Vertical scroll DISABLED
         │
         └──► User releases swipe
                  │
                  ├──► onScrollEndDrag fires
                  │
                  └──► onMomentumScrollEnd fires
                           │
                           └──► onHorizontalScrollEnd()
                                    │
                                    ▼
                           PropertyReelsView
                                    │
                                    └──► setTimeout(() => 
                                         setFeedScrollEnabled(true), 50ms)
                                              │
                                              ▼
                                     FlatList.scrollEnabled = true
                                              │
                                              └──► Vertical scroll ENABLED
